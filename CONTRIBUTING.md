# Contributing to Godot Wild Jam Accessibility Scripts

Thanks for wanting to contribute to Godot Wild Jam Accessibility Scripts!

Please see the [Roadmap](ROADMAP.md) for a list of desired features.

## Guide
Steps to contributing:
1. Fork the repository.
2. Create a branch.
3. Fix a bug or add a feature.
4. Review, clean up, and reduce changes to a minimum.
5. Submit a pull request to `GodotWildJam/gwj-accessibility-scripts:main`.
6. Respond to comments and requests from review.
